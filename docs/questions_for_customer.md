# Уточняющие вопросы и зафиксированные ответы

Ниже — ваши ответы (зафиксированы) + принятые решения для запуска MVP.

## 1. Бизнес и процесс

1. **KPI первого релиза**  
   **Ответ:** стартовая цель 500–1000 лидов, главный ориентир — конверсия.
2. **Ниши**  
   **Ответ:** любые ниши.
3. **География**  
   **Ответ:** гибко — отдельные города, список городов, регионы или вся РФ.
4. **Допустимый % мусорных лидов**  
   **Ответ:** минимальный; обязательны фильтры и антидубли.

## 2. Источники данных

5. **Источники MVP**  
   **Ответ:** Яндекс Карты, 2ГИС, сайты (с исключением мусорных агрегаторов).
6. **Нужен ли вход через cookies/auth**  
   **Ответ:** пока нет (если потребуется, добавим как phase-2).
7. **Прокси/anti-captcha бюджет**  
   **Ответ:** стартуем без этого, подключаем позже при росте объемов.

## 3. Поля и качество данных

8. **Обязательные поля лида**  
   **Ответ:** телефон, email, сайт, адрес, категория — обязательны где доступны.
9. **ИНН/ОГРН**  
   **Ответ:** только при наличии.
10. **Проверка валидности телефонов/email**  
   **Ответ:** нужна проверка правильного формата (без дозвона/SMTP в MVP).
11. **Скоринг качества контакта**  
   **Ответ:** внедряем (по моему предложению) легкий confidence score 0–100.

## 4. Колл-центр и статусы

12. **Список статусов звонка**  
   **Ответ:** разработать оптимальный список для MVP (см. `docs/final_spec.md`).
13. **Скрипты звонка в интерфейсе**  
   **Ответ:** обязательно.
14. **Запись разговоров**  
   **Ответ:** в MVP только лог результата (без записи).
15. **Закрепление лидов за менеджером**  
   **Ответ:** после обработки хранить в БД ответственного и статус; поддержать возврат в очередь по правилам.
16. **SLA/напоминания по перезвонам**  
   **Ответ:** обязательно; особенно для теплых лидов и недозвонов.

## 5. Роли и доступы

17. **Роли на старте**  
   **Ответ:** минимально (админ + менеджер), операторы подключаются позже.
18. **Кто редактирует источники/статусы/пользователей**  
   **Ответ:** только админ.
19. **Нужен ли аудит действий**  
   **Ответ:** да, включая визуальный график активности.

## 6. UI/UX

22. **Референсы UI**
