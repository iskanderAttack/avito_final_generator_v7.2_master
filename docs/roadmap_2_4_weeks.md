# Roadmap на 2–4 недели

## Неделя 1 — База платформы
- Инициализация репозитория структуры:
  - `backend/`, `frontend/`, `workers/`, `infra/`.
- Backend skeleton (FastAPI), auth (JWT), RBAC.
- Подключение PostgreSQL + Alembic.
- Базовые сущности: users, leads, statuses, history.
- Docker Compose для локального запуска.

## Неделя 2 — Парсер и качество данных
- Коннектор Яндекс Карт.
- Коннектор сайтов.
- Нормализация и валидация полей.
- Дедупликация + confidence score.
- Сохранение в БД и базовые API-эндпоинты выдачи лидов.

## Неделя 3 — UI и call-center workflow
- Экран логина.
- Экран списка лидов (фильтры/поиск/сортировка).
- Экран карточки лида + скрипт звонка + комментарии.
- Реализация статусов и таймлайна изменений.
- Напоминания/задачи на перезвон (SLA).

## Неделя 4 — Стабилизация и релиз MVP
- Экспорт CSV/XLSX + Google Sheets.
- Аудит-лог и график активности пользователей.
- Smoke-тесты основных сценариев.
- Документация запуска и инструкция для менеджера/админа.
- Подготовка первой пилотной выгрузки 50 лидов.
